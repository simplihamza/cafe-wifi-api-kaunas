☕ Cafe & Wifi API

Find cafes in Kaunas with wifi, sockets, seating and coffee price info. A small Flask + SQLite API built as a learning project.

Read

GET /random

Returns a single randomly selected cafe as JSON.

GET /all

Returns every cafe, sorted alphabetically by name.

GET /search

Returns cafes matching a location, or a 404 if none match.

location required — e.g. Laisvės al.

Create

POST /add

Creates a new cafe from form-encoded fields.

name required
map_url required
img_url required
location required
seats required
coffee_price optional
sockets, toilet, wifi, calls optional, true/false

Update

PATCH /update-price/<cafe_id>

Updates a cafe's coffee price.

new_price required — query param

Delete

DELETE /report-closed/<cafe_id>

Deletes a cafe, e.g. to report that it has closed down.

api_key required — query param
Base URL: http://127.0.0.1:5000 · all responses are JSON
